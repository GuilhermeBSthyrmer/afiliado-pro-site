As quatro lojas que mais circulam nos grupos

O app reconhece o link mesmo encurtado (shp.ee, meli.la, amzn.to, a.co) e gera o link de afiliado pelo caminho que cada loja oferece.

  • Shopee

    Preço, foto e link de afiliado direto da API oficial de afiliados da Shopee.

  • Mercado Livre

    Dados pela API de catálogo e link no formato vitrine meli.la, igual ao do painel de afiliados.

  • Amazon

    Link com a sua Associate Tag, inclusive quando a oferta chegou como amzn.to.

  • AliExpress

    Link pela API de afiliados com o seu Tracking ID. Produto fora do programa sai com o link original.

Do grupo dos outros para o seu, em quatro passos

  1. 1

    Conecte

    Leia o QR Code com o WhatsApp. No Telegram, entre com o número e o código que chega por SMS.

  2. 2

    Escolha de onde vêm as ofertas

    Marque os grupos e canais que o app vai vigiar. Se quiser, ele também busca ofertas sozinho de tempos em tempos, pelo nicho que você definir.

  3. 3

    Diga para onde elas vão

    Cada grupo de destino pode ter o próprio nicho. Grupo sem nicho recebe tudo.

  4. 4

    Ele posta

    As ofertas entram numa fila e saem com intervalo entre uma e outra, no modelo de anúncio que você montou.

Feito para ficar ligado o dia inteiro

  • Reconecta sozinho. Se a internet cai, ele tenta de novo com espera crescente e avisa na tela que o WhatsApp caiu.
  • Não repete anúncio. A mesma oferta não sai duas vezes no mesmo grupo, nem quando chega por dois grupos diferentes.
  • Oferta vencida não volta. O que passou da hora não é reanunciado depois.
  • Tenta de novo quando a loja barra. A captura que falhou por bloqueio volta para a fila com espera dobrando, até seis vezes.
  • Pausou, parou. A fila respeita a pausa na hora.
  • Registro que explica. Cada captura diz de qual grupo veio, e a tela de registros exporta tudo em CSV.

Roda no seu computador

Produtos, grupos e histórico ficam num banco de dados no seu PC, não num servidor de terceiros. A sessão do Mercado Livre é guardada cifrada pelo próprio Windows, e o app se atualiza sozinho quando sai versão nova.

Dúvidas

Preciso deixar o computador ligado?

Sim. O Afiliado Pro é um app para Windows e trabalha enquanto está aberto. Se o PC desligar, ele reconecta sozinho quando você abrir de novo.

Preciso ter conta nos programas de afiliados?

Sim. O link gerado é o seu, então você precisa estar cadastrado no programa de cada loja que quiser usar e informar as credenciais nas configurações.

E o preço no Pix e o cupom?

Nenhuma das lojas entrega esses dados pela API. Você preenche no produto e eles entram no anúncio pelas variáveis {pix_line} e {coupon_line}. O link da página de cupons também vira link seu.

Funciona no Telegram?

Sim, para monitorar e para postar. Você conecta pelo número e pelo código que chega por SMS.

Tem versão para Mac ou para celular?

Ainda não. Hoje o app é só para Windows.
